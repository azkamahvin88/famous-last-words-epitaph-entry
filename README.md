A make.fun entry for **Famous Last Words: The Funniest Epitaph**: one line of famous last words as a tombstone epitaph — 60 characters — a dead man asks Death for five more minutes, and Death laughs. The program writes exactly that line to `/output/entry.txt`.

> Here I lie. I asked Death for five more minutes. He laughed.

"Here I lie" is the first-person epitaph frame, so the line is both dying speech (the plea to Death) and something carved in stone. The joke is the universal snooze-button plea denied forever: you ask Death for five more minutes, and Death laughs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
